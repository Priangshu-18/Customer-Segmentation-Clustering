# Customer Segmentation using Clustering

An unsupervised machine learning project that segments customers into distinct groups based on purchasing behavior using K-Means clustering.

---

## Overview

- Performs EDA on the Mall Customers dataset
- Selects optimal cluster count using the Elbow Method and Silhouette Score
- Applies K-Means clustering to group customers by Annual Income and Spending Score
- Visualizes distinct customer segments for business insight

## Tech Stack

Python, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## Run

```bash
pip install -r requirements.txt
jupyter notebook customer_segmentation.ipynb
```
